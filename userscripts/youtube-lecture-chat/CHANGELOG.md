# 更新记录

## 1.2.0
- 拉灯开关改为只切换留言板自己的深色 / 浅色，不再改动 YouTube 页面主题；没拉过时留言板跟随 YouTube 主题。

## 1.1.0
- 留言板右上角加入台灯拉绳开关，点击或往下拉一下切换 YouTube 深色 / 浅色，选择会被记住；在 YouTube 菜单里换主题时以菜单为准。

## 1.0.0
- 在 YouTube 观看页右侧用「课堂留言」面板替换推荐视频，可一键恢复推荐。
- 留言自动记录开始输入时的视频时间戳和前后字幕，按视频时间排序，点击时间戳跳转。
- 「？没懂」「⭐ 重点」快捷按钮、反引号聚焦输入框，输入时不触发 YouTube 快捷键。
- 每个视频的留言分开保存，可一键复制为 Markdown 交给 Agent 总结。
- 预留 AI 助教接口，回复显示在疑问下方并随留言导出。
