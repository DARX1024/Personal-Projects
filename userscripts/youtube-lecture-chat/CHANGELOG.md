# 更新记录

## 1.6.0
- 悬停留言时在删除按钮旁出现铅笔按钮，可原地修改这条留言的文字：Enter 保存，Shift+Enter 换行，Esc 取消，点到别处自动保存。
- 留言的编辑、删除按钮也能用 Tab 键聚焦。

## 1.5.0
- 点击留言前的类别标记（❓💡⭐ 或像素皮肤的文字标签）即可在疑问、想法、重点之间切换，忘了打问号也能事后改。

## 1.4.1
- 方格笔记本的台灯吊坠改为浅色时点亮、深色时熄灭，与开灯关灯的直觉一致。

## 1.4.0
- 留言分为「疑问」「想法」「重点」三类：以问号结尾的是疑问，其余都是想法，以问号开头不再算疑问。
- 新增「💡 想法」快捷按钮：先在当前时间占位，接着输入的文字补进这条留言；按 Esc 放弃补写，占位保留。
- 想法在默认皮肤中显示 💡，在像素皮肤中显示「想法」标签。

## 1.3.0
- 新增三款像素皮肤：RPG 对话框（血瓶吊坠）、月夜自习（星星吊坠）、方格笔记本（台灯吊坠），每款都有深浅两套配色，随拉灯切换，关灯时吊坠会发光。
- 留言板右下角加入「皮肤」上拉选单，可用鼠标或方向键选择，选择会被记住。
- 在留言板里按方向键、空格等不再触发 YouTube 的播放快捷键。

## 1.2.0
- 拉灯开关改为只切换留言板自己的深色 / 浅色，不再改动 YouTube 页面主题；没拉过时留言板跟随 YouTube 主题。

## 1.1.0
- 留言板右上角加入台灯拉绳开关，点击或往下拉一下切换 YouTube 深色 / 浅色，选择会被记住；在 YouTube 菜单里换主题时以菜单为准。

## 1.0.0
- 在 YouTube 观看页右侧用「课堂留言」面板替换推荐视频，可一键恢复推荐。
- 留言自动记录开始输入时的视频时间戳和前后字幕，按视频时间排序，点击时间戳跳转。
- 「？没懂」「⭐ 重点」快捷按钮、反引号聚焦输入框，输入时不触发 YouTube 快捷键。
- 每个视频的留言分开保存，可一键复制为 Markdown 交给 Agent 总结。
- 预留 AI 助教接口，回复显示在疑问下方并随留言导出。
